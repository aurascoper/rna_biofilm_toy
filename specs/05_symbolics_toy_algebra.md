Symbolics.jl algebra for the toy. Status: spec only, no code; no package was installed or run for this page. Gate: none; it reads no run output and can start whenever. It is a second, independent derivation of arithmetic the engine already performs, which is its whole value, so the controls matter more than the exercises.

Defensive core, which is one fact: simplify is not canonical in any computer algebra system. Two equal expressions may reduce to different printed forms and two different ones to the same wrong form, so simplify(a) == simplify(b) is unsound as an equality test in both directions. The sound symbolic form is iszero(simplify(a - b)), and the independent detector is numeric substitution at random points compared to floating-point tolerance, which plays the role that agreement with the routine plays in section 3 of bioenergy_toys.jl. Every identity below carries a planted sign defect that must turn both detectors red; if only one fires, the other is not wired up. Verify first, before anything else: whether == on two Num values returns a Bool or builds a symbolic equation, because a test written as a == b is meaningless if it is the latter.

S1, the selection coefficient. With k = 0.25, own purine u, neighbours' purine sum S, local flux F and decay constant c, damage per step is F exp(-k u S) c and the survival time of an organism that never replicates is t = exp(k u S)/(F c). Derive d(ln t)/du = k S exactly, independent of flux. Expected values, computed here and to be written into the file as the test: with neighbours at purine 1.5, the survival-time gain for one +0.05 purine mutation is 0.0 percent at 0 neighbours (S = 0), 3.8 percent at 2 (k S = 0.75), 7.8 percent at 4 (k S = 1.5), 16.2 percent at 8 (k S = 3.0). The consequence is a diagnosis: selection on purine is strong, not weak, so the genotype columns of the CSV are frozen purely by mutation supply (three or four events of plus or minus 0.05 per run at MUTATION_RATE 0.02), and the only lever that would move them is MUTATION_RATE, not the physics; and purine is worth exactly nothing to an isolated organism, so purine and clustering are not separable traits. Control: perturb k in one of the two sides and require both detectors to fail.

S2, the index law. For an interior strip of height h spanning all WIDTH columns on the cylinder, derive mean occupied degree = 8 - 6/h, mean available degree = 8, N = WIDTH h, and hence clustering_index = (8 - 6/h) (WIDTH HEIGHT - 1) / (8 (N - 1)), which falls like 2499/N at fixed shape; for a strip touching an edge row the available degree is 8 - 3/h instead. Expected values measured here for h = 3, 6, 10, 20 (N = 150, 300, 500, 1000): index 12.58, 7.31, 4.63, 2.41. This is the confound that makes an unmatched comparison between arms manufacture the predicted sign, and tests/test_engine.py pins it numerically; this page gives it a formula. Control: drop the -6/h term and require both detectors to fail.

S3, the ledger identity and the monomer steady state. Prove symbolically that M(t) - M(t - 1) = injected_gross - inject_clip - diffusion_clip - birth_sink + death_return holds for one site's update composed of injection with clamp, a conservative transfer, a birth deduction and a clamped death return, so the identity the runner asserts numerically every step is a theorem rather than an observation. Then solve the steady state of the vent disk under constant injection against the replication sink, treating the colony as a uniform consumer at the replication threshold, to answer whether the vent can sustain the population at all, a question the toy raises and never asks. Control: flip the sign of birth_sink and require both detectors to fail.

Confident API names: @variables, simplify, substitute, expand, Differential, expand_derivatives, the Num wrapper. Verify before use: the == question above; whether ~ is the equation constructor and how an Equation is tested; iszero semantics on a symbolic zero versus a structurally nonzero expression that happens to be zero. Do not wait for a Taylor-expansion helper; build expansions from Differential and a finite sum by hand.
